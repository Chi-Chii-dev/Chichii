Place your background music file here named exactly:

    calm-down.mp3

(i.e. static/audio/calm-down.mp3)

The site loads this file for the gentle background music on the opening
screen. It is intentionally NOT included for copyright reasons — add your
own copy of "Calm Down" by Rema (or any .mp3 you like) with that filename.

Tip: an .ogg or .m4a will also work if you update the <audio src> in
templates/index.html accordingly.
